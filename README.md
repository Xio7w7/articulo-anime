# articulo-anime

Tarea de CSS básico para la clase de Programación Orientada al Usuario.

Hice un artículo con formato IEEE a una columna usando solo HTML y CSS. El tema es de dónde vienen los animes más populares de Crunchyroll (si son de manga o de novela ligera) y a qué público estaban dirigidos originalmente.

La página se puede ver aquí: https://xio7w7.github.io/articulo-anime/

## Archivos

- index.html: el contenido del artículo
- style.css: los estilos

Para el diseño solo usé lo que se pedía en la actividad: selectores de etiqueta, clase e id, tipografía, colores, márgenes, bordes y :hover. No usé flex, grid, position ni float.
